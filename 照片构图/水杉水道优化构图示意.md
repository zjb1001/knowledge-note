## 视觉焦点层级

```
第1层（主焦点）：白桥 ★
    │
    ├── 位置：画面中心偏上（黄金分割点）
    ├── 颜色：白色，在灰褐树林中对比强烈
    └── 形状：弧形桥洞，柔和优美
    │
第2层（次焦点）：水道透视
    │
    ├── 从前景向远处收窄
    ├── 形成强烈纵深感
    └── 引导视线至桥
    │
第3层（辅助）：两侧树木
    │
    ├── 形成天然画框
    ├── 垂直线条增加秩序感
    └── 左下角柳树嫩绿点缀
    │
第4层（基底）：水面倒影
    │
    └── 镜像对称，增加静谧感
```

```
调整前：               调整后：
┌─────────┐          ┌─────────┐
│ 偏灰白   │    →    │ 清冷感   │

具体参数建议：
- 色温：-10（偏冷）
- 对比度：+20
- 阴影：-15（加深树林）
- 高光：-20（压天空）
- 清晰度：+15
- 暗角：轻微（聚焦中心）
```
