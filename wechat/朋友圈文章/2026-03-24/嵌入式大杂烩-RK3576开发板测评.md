## 引言

2025年，嵌入式AI突然爆发！没有NPU（神经网络加速单元）的芯片，都不敢说自己能跑AI。在这场硬件厮杀中，**瑞芯微RK3576** 直接杀出重围：

- **4核Cortex-A72 + 4核Cortex-A53**
- 内置 **6TOPS NPU**
- 支持 **INT4/INT8/FP16混合运算**
- 实测推理性能高达 **45fps**

## EASY EAI Orin Nano 开发板

广州灵眸科技有限公司推出的基于RK3576的工业开发板。

### 核心优势

**资料多到离谱** —— 不管硬件还是软件资料，全公开，教程详细到像"手把手教"

### 通信接口

| 接口 | 规格 |
|------|------|
| 以太网 | **双千兆网口**（RTL8211F方案） |
| USB | USB 3.0×2 Type-A + USB 2.0 Type-C OTG |
| PCIe | PCIE 2.1 M.2接口（可插26TOPS算力卡 or NVMe SSD） |
| 无线 | WiFi + 蓝牙5.2 + **星闪（SLE1.0）**三模 |
| 存储 | TF card |

### 音视频接口

| 接口 | 规格 |
|------|------|
| 摄像头 | 2×MIPI CSI |
| 屏幕 | 1×MIPI DSI |
| HDMI | HDMI 2.1（8K@30Hz / 4K@120Hz） |
| 音频 | 3.5mm耳机 + 2×speaker输出（3W/4Ω）+ MIC |

### 工业级设计细节

- **全板ESD防护**：USB/网口/HDMI全保护，防静电击穿
- **自恢复保险丝 + TVS管**：12V输入防反接
- **核心板可拆卸设计**：广濑连接器，不用烙铁，直接拔插

### 软件支持

- Buildroot-2024.2
- Android 14
- Ubuntu
- Qt-5.15.11图形界面开发工具
- 完善的SDK开发套件

## 开发板硬件细节

### 设计特点

- **核心板+底板组合形式**
- **广濑连接器**（带定位柱）板对板连接
- 尺寸：100×120mm
- 比传统邮票孔方案更方便 —— 不用电烙铁，徒手就能拆装

### USB接口

- 双层USB3.0 TYPE-A接口
- 支持USB3.1 Gen1（等同于USB3.2 Gen1 / USB3.0）
- 高达**5Gbps**通信速率
- 支持SS/HS/FS/LS协议，向下兼容USB 2.0

### Type-C接口

- 全功能Type-C接口
- 内置USB 2.0 OTG PHY
- 兼具系统调试和固件下载功能
- **支持DP1.4视频输出**

### 以太网设计

- 2路千兆以太网
- 支持10/100/1000 Mbps自适应
- 每路配有G2401CE隔离变压器
- 采用**瑞昱RTL8211F**芯片方案（符合IEEE 802.3标准）
- 板背专门设计ESD防护
