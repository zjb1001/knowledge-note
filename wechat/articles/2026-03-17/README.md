1. EMB作为独立域控系统

### 3. AUTOSAR项目实战(1)-数据地址访问对齐问题分析
**发布时间**: 2025-01-08

**核心内容**:
- 问题：Main函数调用Os_Init后发生异常Trap
- 异常类型：Class 2 ALN（数据地址对齐陷阱）
- D[15]寄存器保存TIN号
- D[4] = (TCN << 16) | TIN

**诊断方法**:
- 查看DSTR寄存器定位Trap类型
- 分析函数调用栈
- 检查中断Source号配置

---

### 4. AUTOSAR功能安全之内存分区与实现
**发布时间**: 2025-10-14

**核心内容**:
- 内存分区保护配置方案
- 三种用例场景：
  1. SWC位于同一分区：可互相访问RAM
  2. 不同分区中的SWC：无法互相访问
  3. MCAL驱动程序：需外设空间读写权限

**关键机制**:
- 限制内存和内存映射硬件访问
- 用户模式下SWC对CPU指令访问受限
- 保护只读内存段和内存映射硬件

### 5. AUTOSAR架构下NvM进入无限循环问题分析
**发布时间**: 2025-10-12

**核心内容**:
- 问题现象：ECU休眠过程中被唤醒，NvM_MainFunction超时导致看门狗复位
- 根因：NvM User非法操作导致NvM模块进入无限循环
- 异步操作特性：NvM Stack(NvM, Fee, Fls)均为异步操作

**排查方法**:
- 添加log定位具体NvMBlock
- 分析NvM模块源码逻辑
- 检查Block操作合法性

### 2. 高速PCB设计指南—信号完整性
**发布时间**: 2025-08-09

**核心概念**:
- 信号完整性（SI）：信号传输过程中保持原始特性和质量的能力

**常见问题**:
1. **反射**：阻抗变化导致信号功率反射
   - 解决：保持传输线恒定阻抗，良好地面平整度，源端串联端接

2. **振铃**：电压/电流输出振荡
   - 解决：导体靠近地平面，差分布线，减少并行长度

3. **过孔残桩（Stub）**：过孔剩余部分导致谐振
   - 解决：避免多余线头，减少Stub长度

4. **串扰**：信号间 unwanted coupling
   - 解决：正交布线，增加间距，选用低介电常数材料

## 七、嵌入式大杂烩（知识技能 P2）

### 1. 嵌入式开发调试利器Sanitizer
**发布时间**: 2025-06-29

**核心内容**:
- Google开源工具集，用于检测内存泄露等问题

**三大检测器**:
1. **AddressSanitizer(ASan)**：检测缓冲区溢出、使用已释放内存
   - 编译参数：`-fsanitize=address -g`

2. **ThreadSanitizer(TSan)**：检测线程数据竞争、死锁
   - 编译参数：`-fsanitize=thread -g`

3. **MemorySanitizer(MSan)**：检测未初始化内存使用

**限制**:
- ASan与TSan不能同时使用
- TSan可检测部分内存问题（使用已释放堆内存），但检测不出栈缓冲区溢出

### 3. 嵌入式开发常用调试方法
**发布时间**: 2024-06-15

**log输出方法**:
1. **串口输出**：最常用，但需串口驱动
2. **IO模拟UART**：无串口时的替代方案
3. **SWO/SWD调试**：ARM Cortex-M系列

**IO模拟UART实现**:
- 找空闲普通IO口
- 使用定时器产生精确延时（如1us）
- 根据波特率计算每个bit延时
- 在确定时间输出高低电平模拟波形

**关键代码**:
```c
// 计算波特率延时
baud_delay = 1000000 / baud_rate;

// TIM4定时器产生1us延时
TIM_InitStructure.TIM_Period = 41; // 1us timer
```
