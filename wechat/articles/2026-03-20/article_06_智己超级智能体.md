# 智己的"超级智能体"，到底是什么？

> **来源**: 汽车电子设计  
> **日期**: 2026-03-19  
> **原链接**: https://www.ednchina.com/technews/39252.html

## 核心要点

2026年3月18日，智己在技术发布会上提出了 **IM Ultra Agent 智己超级智能体**，宣称这是"车载AI迈向具身智能的跨代际飞跃"——每台智己车都能拥有一个专属AI司机助理。

## IM Fusion Nova架构：舱驾一体的底层逻辑

汽车行业里大部分车企的智能架构，是把智驾和智舱分开做的：智驾一套芯片、一套算法，智舱一套芯片、一套系统。

好处是开发解耦，坏处是两个系统之间协调成本高，信息流转有损耗。

**IM Fusion Nova做了一件事**：从底层把智驾和智舱融合成一套架构，用异构计算的方式，让两套系统在同一个硬件基础上协同工作。

这样做的好处有三个层面：
1. **响应更快** — 信息不用跨系统传递，直接内部处理
2. **感知更全** — 智驾摄像头看到车外，智舱摄像头看到车内，融合后AI不仅知道"前面有行人"，还知道"驾驶员正在看手机没注意到"
3. **场景理解更深** — 综合车外环境、车内状态、用户意图做统一判断

## 具身智能的落地

智己把这一套架构的核心逻辑定义为"具身智能"。放到车上，具身智能的落地就是：

> AI能直接控制方向盘、刹车、油门——不是发指令，是直接控车。

这和现在的语音助手"帮你操作手机"不是一回事，是完全不同的技术深度。

## 座舱体验：与阿里千问合作

智己选择和阿里千问合作，把千问大模型接入了车机系统。

**千问的背景**：
- 累计下载量超过10亿次
- 衍生模型超过20万个
- Hugging Face开源模型榜单全系列包揽前四
- 美国权威科技媒体Wired判断"2026年将属于千问"

选千问的逻辑：中文场景理解能力最强，本地化生态最完整，背靠阿里生活服务体系的壁垒最高。

## 全域代劳：座舱体验质变

IM Ultra Agent想做的是把中间那些需要用户主动参与的动作省掉。

**示例场景**：
> 用户说"我有点累了，想找个安静的地方休息一下"
> 
> 系统会综合当前位置、时间、用户历史偏好，筛选出符合条件的地点，然后直接启动导航。

用户省掉了"打开App、输入目的地、判断哪个选项"这些中间步骤。

**生态接入**：支付宝、淘宝、飞猪、高德等高频应用将接入IM Ultra Agent。

## 灵蜥数字底盘：全线控量产落地

线控底盘这项技术，之前只有少数豪华品牌在部分高端车型上尝试过，但因为安全冗余方案不成熟、成本过高等原因，一直没有大规模推开。

**智己的核心进展**：

| 指标 | 参数 |
|------|------|
| 响应速度 | 20毫秒（比传统转向系统快4倍以上） |
| 安全冗余 | 三重冗余（国标要求双重） |
| 测试条件 | 车速160km/h、-28°C至+50°C、连续大角度转向 |
| 性能衰减 | 控制在5%以内 |
| 实验项目 | 11400多项 |

**极端工况示例**：
假设在120km/h高速行驶中，前轮转向系统完全失效——系统会通过后轮转向和单点制动协同，帮助车辆安全靠边停车并制动。

**产业意义**：
智己是线控转向新国标的牵头制定单位。LS8的量产落地，意味着20-40万价格段的国产车型，把豪华品牌旗舰车型才有的机械配置，下放到了普通消费者触手可及的价格区间。
